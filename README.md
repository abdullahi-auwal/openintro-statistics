# OpenIntro Statistics with R
A hands-on journey through statistics, data analysis, and R programming using **OpenIntro Statistics**.
This repository documents my progress as I work through the textbook and its accompanying R labs, while also using the datasets and examples to strengthen my practical R skills.
Rather than only reading the statistical concepts, I am trying to **understand, implement, visualize, and reproduce** them using R.
---

## Objectives

Through this project, I aim to:

- Strengthen my understanding of fundamental and intermediate statistical concepts.
- Develop practical proficiency in **R** for statistical analysis and data visualization.
- Work with real-world datasets used in statistical examples.
- Complete the accompanying OpenIntro R labs.
- Reproduce selected tables, graphs, and analyses from the textbook.
- Become more comfortable translating statistical concepts into R code.
- Develop reproducible data-analysis habits that I can apply to biomedical research.
- Build a stronger foundation for future research involving clinical and medical data.

---

## Main Resource

**OpenIntro Statistics**

https://www.openintro.org/book/os/

The textbook provides the main statistical concepts, examples, datasets, and exercises used throughout this project.

I will also make use of the accompanying R labs and datasets where available.

---

## What I Am Doing

For each section or chapter, I will generally work through three complementary activities:

### 1. Learn

Read the relevant sections of the textbook and work through the examples and exercises.

### 2. Practice

Complete the accompanying R labs and write my own R code to explore the concepts.

### 3. Reproduce

When the textbook presents a graph, table, or analysis using an available dataset, I will attempt to reproduce it independently in R.

The goal is not simply to obtain the same output, but to understand:

**Data → Code → Analysis → Visualization → Interpretation**

## Figure & Analysis Reproduction

One of the main components of this project is reproducing selected examples from the textbook.

For each reproduction, I will try to:

1. Locate the original dataset.
2. Identify the variables used.
3. Understand what the original visualization or analysis is demonstrating.
4. Write the R code independently.
5. Reproduce the result.
6. Compare my result with the textbook.
7. Document anything I learned from the process.

This is intended to help me move beyond simply *reading* statistical results toward understanding how they are produced.
